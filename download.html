Hand Gestures

Webcam hand-tracking server, drawing board, and floating keyboard UI.

Setup Instructions
  1. Install Python 3.14. Check the box "Add Python To PATH".
    Download Python
  2. Download and extract the .7z archive below.
  3. Open Command Prompt in that folder.
  4. Install dependencies:
    pip install websockets pyautogui pywin32
  5. Start the local server:
    python mouse_server.py
  6. Double-click home.html to open the tracking UI.
