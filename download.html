Perceptus Flow v2.5.0

Autonomous touchless machine vision, multimodal AI co-pilot & frameless glass cockpit. Control Windows using your standard webcam.

Setup Instructions
  1. Download PerceptusFlow.exe standalone application or grab the Python source package archive.
  2. For .EXE (Standalone): Run directly on Windows (native 60 FPS Win32 Kalman hardware cursor bridge).
  3. For .7Z (Python Package): Install dependencies (pip install websockets pyautogui pywin32) and run python mouse_server.py.
  4. Allow webcam access to enable touchless cursor control, pinch clicks, and spatial drawing.
